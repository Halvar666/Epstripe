# Changelog

## 1.0.0rc1

First public release candidate.

### Visual
- Added Winstripe/Thunderstripe-style mail, compose, Address Book and supporting UI icons.
- Corrected the Winstripe 1.9.9 Tag / Back / Forward toolbar mapping.
- Kept Epyrus-compatible toolbar geometry with 20×20 normal and 16×16 small toolbar icons.
- Increased the main mail toolbar height for improved vertical spacing.
- Improved inactive-selection readability in the folder and message/thread panes.
- Added a 32×32 Get Messages icon and refreshed theme preview artwork.

### Compatibility
- Added separate Linux and Windows platform layers.
- Added Windows titlebar/caption controls based on Epyrus 2.2.1 Win64 Default behavior.
- Fixed Windows Menu Bar text contrast.
- Fixed Windows main-toolbar split-button/dropmarker rendering.

### Additional UI
- Added supplemental xpDefault colored buttons assets for Preferences, S/MIME, Activity Manager, Address Book and New Mail Account UI.
- Added Calendar/Lightning skin support for Calendar, Tasks, Add as event and Add as task icons.
