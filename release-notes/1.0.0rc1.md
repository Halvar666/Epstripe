# Epstripe 1.0.0rc1

First public release candidate of **Epstripe**, a Winstripe/XP-style complete theme for **Epyrus**.

## Added
- Winstripe/Thunderstripe-style mail, compose, Address Book and supporting UI icons.
- Supplemental xpDefault assets for Preferences, S/MIME, Activity Manager, Address Book and New Mail Account UI.
- Calendar/Lightning skin support for Calendar, Tasks, Add as event and Add as task icons.
- Separate Linux and Windows compatibility layers.

## Fixed
- Corrected Winstripe 1.9.9 Tag / Back / Forward toolbar mapping.
- Improved inactive-selection readability in the folder and message/thread panes.
- Improved main mail toolbar vertical spacing.
- Added Windows titlebar/caption controls based on Epyrus 2.2.1 Win64 Default behavior.
- Fixed Windows Menu Bar text contrast.
- Fixed Windows split-button/dropmarker rendering in the main mail toolbar.

## Notes
- Compatible with Epyrus 2.0.0–2.2.*.
- Some localized Epyrus language packs may still show “Thunderbird” in the app menu button. This is a language-pack branding issue, not a theme issue.
